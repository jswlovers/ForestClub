# iPhone 앱 빌드 10

- iPhone 16 Pro: `ForestClub-iPhone16Pro-iOS17-build10.ipa`, 최소 iOS 17.0, arm64.
- iPhone SE: `ForestClub-iPhoneSE-iOS12-build10.ipa`, 최소 iOS 12.0, arm64.
- 기존 공유 네이티브 홈 화면과 회원 서비스를 포함하며 운영 서버에 자동 연결합니다.
- Xcode 16.4 Release 실제 기기용 빌드 성공. CFBundleVersion=10.
- 두 IPA의 ZIP 무결성, 원본 앱 복사 일치, arm64 아키텍처와 최소 OS 버전을 확인했습니다.
- 두 앱은 서명되지 않았으며 설치 전에 설치 도구 또는 Xcode로 서명해야 합니다.
- 실제 iPhone SE의 iOS 12 설치·실행은 이번 작업에서 확인하지 않았습니다.
- 기존 IPA는 보존했습니다.
