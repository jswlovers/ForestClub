# ForestClub 빌드 5

쪽지, 코인, 프로필, 멤버십 지원, 동행 신청, 고객센터를 공유 UIKit 화면으로 옮겼습니다. 모든 회원 API는 앱 안에서 같은 로그인 쿠키를 사용합니다. 로그인 세션은 키체인에 보관해 앱 재실행 시 복원합니다. 외부 웹사이트 로그인은 필요하지 않습니다.

- iPhone 5s / iOS 12.5.7: `ForestClub-iOS12-build5.ipa` (최소 iOS 12.0)
- 최신 iPhone/iPad: `ForestClub-iOS18-build5.ipa` (최소 iOS 18.5)
- 모두 실제 기기용 arm64, 빌드 번호 5, 서명 없는 IPA입니다. 설치 도구에서 서명해야 합니다.
- 이전 빌드의 IPA는 보존합니다. 새 설치에는 빌드 5를 사용합니다.

검증: 두 기기용 Release 빌드 성공, IPA 압축 검사 및 최소 OS/아키텍처 확인. iPhone 16 Pro / iOS 18.6 시뮬레이터에서 자동 테스트 5개 통과. 로그인 공유, 로그아웃·만료, 앱 내부 쪽지 전송·코인 조회·프로필 화면 및 앱 재실행 후 키체인 세션 복원을 확인했습니다. UI 테스트는 서명된 시뮬레이터 앱과 로컬 테스트 API를 사용했습니다.

실제 iPhone 5s 설치·실행 및 운영 서버의 전체 기능은 별도 검증이 필요합니다. 실시간 음성·영상 통화 UI와 프로필 사진 업로드는 이번 버전에 포함되지 않습니다.
