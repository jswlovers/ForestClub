# 포레스트클럽 iOS

SwiftUI 기반 iPhone/iPad 앱입니다. iOS 18.5 이상을 대상으로 합니다.

- 홈과 추천 모임
- 골프/여행 필터, 모임 검색과 상세 화면
- 기존 서버 API로 참가 문의 접수 및 남은 자리 갱신
- 회원가입, 로그인, 로그아웃 (앱 실행 동안 세션 쿠키 유지)
- 서버 주소 저장, 연결 오류 안내, 명시적인 예시 모드
- 멤버십/동행/쪽지는 기존 웹 서비스로 이동

## 실행

1. Xcode에서 `forest.xcodeproj`를 엽니다.
2. `forest` 스킴과 iPhone 시뮬레이터를 선택하고 실행합니다.
3. 저장소 루트에서 Node 22.6 이상으로 `npm install`, `npm start`를 실행합니다.
4. 앱의 마이페이지 → 서비스 연결에 `http://localhost:3000`을 입력하고 서버 연결을 누릅니다.

서버 없이도 예시 모임을 탐색할 수 있습니다. 예시 모드에서는 회원가입/로그인과 참가 문의가 비활성화됩니다. 실제 기기에서는 기기가 접근 가능한 HTTPS 서버 주소를 사용합니다. 앱은 서버 루트 주소만 받으며 하위 경로는 지원하지 않습니다.

실제 기기에 설치하려면 Xcode의 Signing & Capabilities에서 개발 팀과 고유한 Bundle Identifier를 설정합니다. App Store 배포용 아이콘과 서명은 별도 준비가 필요합니다.

로그인 정보와 비밀번호는 디스크에 저장하지 않습니다. 앱을 종료하면 다시 로그인해야 합니다. 웹 서비스와 앱의 세션은 별개입니다.

Xcode 16.4로 시뮬레이터용 Debug와 실제 기기용 Release 빌드를 완료했습니다. iPhone 16 Pro 시뮬레이터(iOS 18.6)에서 실행 화면을 확인했습니다. 실제 서버의 회원가입 → 로그아웃 → 로그인 → 참가 문의 흐름과 실제 기기 설치는 아직 검증하지 못했습니다.
