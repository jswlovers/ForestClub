# 포레스트클럽 iOS 12 호환 앱

iPhone 5s / iOS 12.5.7을 위한 별도의 UIKit 앱입니다. 기존 SwiftUI 프로젝트는 forest/에 보존됩니다.

홈, 모임 검색/골프·여행 필터, 참가 문의, 서버 연결, 회원가입/로그인/로그아웃을 제공합니다. 멤버십·동행·쪽지는 기존 웹 서비스로 이동합니다. 서버가 없으면 예시 모임을 표시하고 실제 참가 문의를 비활성화합니다.

빌드 2부터 홈 상단과 하단 탭에서 **전체 메뉴**를 열 수 있습니다. 골프모임·여행모임·계정 설정은 앱 화면으로 이동하며, 클럽 소개·멤버십·후기·프로필·지원 현황·신청함·쪽지함·코인 충전·고객센터는 웹 서비스 이용 안내를 제공합니다. iOS 12에서 지원하는 방식으로 탭 아이콘을 표시합니다.

최신 iPhone 5s용 산출물은 `artifacts/ForestClub-iOS12-build3.ipa`입니다. 서명 없는 파일이므로 Sideloadly에서 서명해 설치합니다. 이전 IPA는 보존합니다.

## Windows에서 설치

1. https://sideloadly.io 에서 Sideloadly 및 공식 안내에 필요한 Apple iTunes/iCloud 구성요소를 설치합니다.
2. iPhone을 USB로 연결하고 잠금을 풀어 컴퓨터를 신뢰합니다.
3. ForestClub-iOS12.ipa를 Sideloadly로 열고 기기와 무료 Apple ID를 선택해 서명/설치를 진행합니다.
4. iPhone 설정 → 일반 → 프로파일 및 기기 관리에서 해당 개발자 계정을 신뢰합니다.

무료 Apple ID의 서명은 7일마다 갱신해야 합니다. iOS 12에는 최신 iOS의 개발자 모드 메뉴가 없습니다. UDID를 앱에 넣을 필요는 없으며, 설치 도구가 연결된 기기로 서명을 준비합니다. 비밀번호는 설치 도구에서 직접 입력하세요.

## 서버 연결

마이페이지 → 서버 주소 설정에서 기기로 접근 가능한 HTTPS 서버의 루트 주소를 입력합니다. localhost는 Windows/Mac의 서버를 가리키지 않습니다. 실제 백엔드가 배포되어 있어야 예시 모드 밖의 기능을 사용할 수 있습니다. 로그인은 앱 실행 동안 유지됩니다.

## 검증

Xcode 16.4로 iOS 기기용 Release 빌드 및 최소 OS 버전/arm64 아키텍처/IPA 구조를 검사합니다. iOS 12 런타임과 실제 iPhone 5s는 이 Mac에 연결되어 있지 않으므로 실제 설치·실행은 검증하지 못했습니다.
