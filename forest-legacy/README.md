# 포레스트클럽 iOS 12 앱

iPhone 5s / iOS 12.5.7을 지원하는 UIKit 앱입니다. 최신 iOS 앱과 `shared/Native/`의 화면 및 API 클라이언트를 함께 사용합니다.

## 빌드 6

- 홈, 골프·여행 모임 검색, 참가 문의
- 전체 메뉴와 마이페이지 회원 서비스 바로가기
- 회원가입·로그인·로그아웃, 키체인에 로그인 세션 보관 및 서버에서 유효성 확인
- 내 프로필 조회·저장
- 멤버십 지원서 제출과 심사 결과 조회
- 동행 신청, 받은/보낸 신청 조회, 수락·거절·취소
- 쪽지 대화 목록, 새 대화, 텍스트 및 파일 전송, 첨부파일의 앱 내부 미리보기
- 코인 잔액, 사용 내역, 무통장입금 충전 신청과 승인 상태 조회
- 고객센터 문의·환불 문의·회원 신고 접수와 답변 조회

회원 기능은 외부 웹사이트를 열지 않고 앱의 같은 로그인 세션으로 서버 API를 호출합니다. 앱 종료 후에도 세션을 키체인에서 복원합니다. 로그아웃, 서버 세션 만료, 계정 정지, 다른 기기에서 같은 계정으로 새 로그인한 경우에는 다시 로그인해야 합니다. 비밀번호는 보관하지 않습니다.

## Windows에서 설치

최신 IPA: `artifacts/ForestClub-iPhoneSE-iOS12-build10.ipa`. 서명 없는 실제 기기용 arm64 빌드입니다. 이전 IPA도 보존됩니다.

1. https://sideloadly.io 에서 Sideloadly와 공식 안내의 Apple 구성요소를 설치합니다.
2. iPhone을 USB로 연결하고 잠금을 풀어 컴퓨터를 신뢰합니다.
3. IPA를 Sideloadly로 열고 연결된 기기와 무료 Apple ID로 서명·설치합니다.
4. iPhone 설정 → 일반 → 프로파일 및 기기 관리에서 개발자 계정을 신뢰합니다.

무료 Apple ID 서명은 7일마다 갱신해야 합니다. iOS 12에는 최신 iOS의 개발자 모드 메뉴가 없습니다. Apple 인증 정보는 설치 도구에서 직접 입력합니다.

## 서비스 연결

`https://forest.sean2022.one:8888`에 자동 연결합니다. 서버 주소 설정 메뉴는 제거했습니다. 회원가입은 운영 서비스의 약관 동의와 본인 정보 사전 확인, 회원 정보 입력 절차를 앱 안에서 진행하며 가입 자체가 멤버십 심사 신청입니다.

쪽지 발송은 기존 서버 정책에 따라 1건당 500코인이 사용됩니다. 첨부는 최대 15MB입니다. 코인 충전 신청은 관리자 입금 확인과 승인을 거쳐 반영됩니다. 프로필 사진 업로드는 현재 앱에 포함되지 않습니다.

보이스톡·페이스톡: 대화창의 통화 버튼에서 보이스톡(초당 10코인) 또는 페이스톡(영상, 초당 100코인)을 고릅니다. 앱이 열려 있으면 받기/거절 창이 뜨고, 대화의 통화 메시지를 눌러도 참여할 수 있습니다. 페이스톡은 상대 화면을 전체로, 내 화면을 작게 보여 주며 음소거·화면 끄기·카메라 전환을 지원합니다. 서버 정책상 보이스톡은 메시지를 주고받은 상대와, 페이스톡은 보이스톡을 나눈 상대와 할 수 있습니다. 앱이 꺼져 있을 때의 착신 알림(푸시)은 아직 지원하지 않습니다. 앱 안 통화는 iOS 14.3 이상에서만 동작하므로 iOS 12 기기(iPhone 5s 등)에서는 안내 메시지만 표시됩니다.

## 검증

Xcode 16.4로 실제 기기용 Release와 시뮬레이터용 빌드를 검사합니다. 공유 로그인 쿠키/로그아웃/만료 테스트 및 로컬 API를 사용하는 앱 내부 로그인 → 쪽지 전송 → 코인 조회 → 프로필 화면 UI 테스트가 있습니다. 실행 방법은 `scripts/tests/README.md`를 참고합니다.

이 Mac에는 실제 iPhone 5s와 iOS 12 시뮬레이터 런타임이 없으므로 iOS 12.5.7 기기에서의 설치·실행과 운영 서버 전체 연동은 아직 검증하지 못했습니다.
