## 1. 시작하기: 회원가입과 로그인

### 회원가입
1. 화면 오른쪽 위 **로그인** 버튼을 누르고 **회원가입** 탭을 선택합니다.
2. 이름, 이메일, 비밀번호(8자 이상)를 입력합니다.
3. **연락처**는 선택이지만 꼭 입력해 두시길 권합니다. 가입 환영, 동행 신청, 새 쪽지 등의 알림 문자가 이 번호로 오고, 비밀번호를 잊었을 때 인증코드를 받는 데도 쓰입니다. 형식은 `010-1234-5678`입니다.
4. **회원가입**을 누르면 바로 로그인됩니다.

> 회원가입은 멤버십 승인과 별개입니다. 가입만으로 클럽 정식 회원이 되는 것은 아니며, 멤버십은 [지원서 심사](#2-멤버십-지원하기)를 거쳐 승인됩니다.

### 로그인과 로그아웃
- 이메일과 비밀번호로 로그인합니다. 로그인은 30일간 유지됩니다.
- **한 계정은 한 곳에서만 로그인됩니다.** 다른 기기나 브라우저에서 로그인하면 이전에 로그인한 곳은 자동으로 로그아웃됩니다.
- 로그아웃은 오른쪽 위 이름(로그인 버튼 자리)을 눌러 나오는 메뉴에서 **로그아웃**을 선택합니다. 모바일에서는 ☰ 메뉴를 사용합니다.
- 짧은 시간에 로그인을 너무 많이 시도하면 잠시 제한됩니다. 잠시 후 다시 시도해 주세요.

### 비밀번호를 잊었을 때
1. 로그인 창에서 **비밀번호를 잊으셨나요?** 를 누릅니다.
2. 가입한 이메일을 입력하고 **인증코드 받기**를 누릅니다.
3. 가입 시 등록한 연락처로 6자리 인증코드가 문자로 옵니다. 코드는 **10분간** 유효합니다.
4. 인증코드와 새 비밀번호(8자 이상)를 입력해 **비밀번호 재설정**을 누릅니다.

연락처를 등록하지 않았다면 인증코드를 받을 수 없으니 고객센터가 아닌 운영진에게 직접 문의해 주세요.

### 비밀번호 변경
로그인한 상태에서 메뉴의 **내 프로필**을 열면 맨 아래 **비밀번호 변경**에서 현재 비밀번호와 새 비밀번호(8자 이상)를 입력해 바꿀 수 있습니다.

### 메뉴 위치
로그인하면 이름(또는 로그인 버튼 자리)을 눌러 아래 메뉴를 쓸 수 있습니다.

| 메뉴 | 용도 |
|---|---|
| 내 프로필 | 프로필·사진·본인 인증·비밀번호 |
| 내 지원 현황 | 멤버십 지원서 심사 결과 |
| 내 신청함 | 동행 신청 주고받기 |
| 쪽지함 | 회원 간 채팅 |
| 코인 충전 | 코인 충전 신청과 내역 |
| 고객센터 | 문의·환불·신고 |
| 로그아웃 | |

화면 위쪽의 **○○ 코인** 배지를 누르면 코인 충전 창이 열립니다.

## 2. 멤버십 지원하기

포레스트클럽은 초대제로 운영되며, 지원 후 다음 순서로 진행됩니다.

1. **온라인 지원서** 제출
2. **서류 심사** (운영진 검토)
3. **멤버 인터뷰**
4. **승인 및 웰컴 라운딩** 초대

### 지원서 작성
1. 화면의 **지원하기** 또는 **멤버십 지원하기 →** 버튼을 누릅니다.
2. 성함, 연락처, 이메일은 **필수**입니다. 연령대, 거주 지역, 직업/업종, 골프 구력, 관심 분야, 추천인(선택), 간단한 소개를 적을수록 심사에 도움이 됩니다.
3. **지원서 제출하기**를 누르면 접수 안내 문자가 옵니다. 심사 결과는 영업일 기준 3일 이내에 안내됩니다.

> 로그인한 상태에서 지원해야 **내 지원 현황**에서 결과를 확인할 수 있습니다. 로그인하지 않고 제출하면 접수는 되지만 이 화면에는 나타나지 않습니다.

### 심사 결과 확인
메뉴의 **내 지원 현황**에서 상태(대기중 / 승인됨 / 거절됨)와 운영진 메모를 볼 수 있고, 결과가 나오면 문자로도 알려드립니다. 거절되면 사유가 함께 안내되며 다음 모집 때 다시 지원할 수 있습니다.

## 3. 내 프로필 관리

메뉴의 **내 프로필**에서 관리합니다. 여기서 입력한 내용은 **동행 신청 후보 목록에서 다른 회원에게 보입니다.**

### 프로필 사진
**사진 변경**을 눌러 이미지(jpg/png/gif/webp, 5MB 이하)를 올립니다. 이 사진은 다른 회원에게 공개됩니다.

### 프로필 정보
연락처, 연령대, 거주 지역, 직업/업종, 골프 구력, 관심 분야, 간단한 소개를 입력하고 **저장하기**를 누릅니다. 모두 선택 사항입니다.

### 인증 배지
프로필과 동행 신청 목록에 신뢰를 보여 주는 배지가 표시됩니다.

| 배지 | 받는 방법 |
|---|---|
| ✓ 본인인증 | 직접 신분증 사진을 올려 신청 → 운영진 승인 |
| 재직인증 | 운영진이 확인 후 부여 (회원이 직접 신청하는 화면은 없음) |
| 골프인증 | 운영진이 확인 후 부여 (회원이 직접 신청하는 화면은 없음) |

### 본인 인증 신청
1. **내 프로필** 안의 **본인 인증** 영역에서 **신분증 업로드**를 누릅니다.
2. 주민등록증·운전면허증 등 신분증 사진(jpg/png/webp, 8MB 이하)을 선택합니다.
3. 접수되면 "신분증 심사가 진행 중이에요"라고 표시됩니다. 심사 중에는 추가 신청이 되지 않습니다.
4. 승인되면 문자가 오고 프로필에 ✓ 본인인증 배지가 붙습니다. 반려되면 사유와 함께 안내되므로 다시 신청할 수 있습니다.

신분증 사진은 본인 확인 목적으로만 쓰이며, **본인과 관리자만 볼 수 있고 다른 회원에게는 공개되지 않습니다.** (프로필 사진과 달리 별도로 보관됩니다.)

## 4. 모임 참가 문의와 동행 신청

메인 화면의 **골프모임**, **여행모임**에 모임 카드가 있습니다. 카드마다 정원과 남은 자리가 표시되며, 남은 자리는 실제 문의 수에 따라 자동으로 줄어듭니다.

### 참가 문의 / 일정 문의
카드의 **참가 문의**(여행은 **일정 문의**) 버튼을 누르면 운영진에게 관심이 전달됩니다. 로그인하지 않아도 누를 수 있지만, 로그인하면 누가 문의했는지 운영진이 알 수 있어 안내가 수월합니다.

### 동행 신청 (로그인 필요)
함께하고 싶은 회원을 지목해 그 모임에 같이 가자고 신청하는 기능입니다.

1. 모임 카드의 **동행 신청**을 누릅니다. 로그인하지 않았다면 로그인 창이 먼저 열립니다.
2. **신청할 회원**을 고릅니다. 선택하면 그 회원의 프로필(연령대, 지역, 골프 구력, 소개, 인증 배지)을 볼 수 있습니다.
3. 전하고 싶은 메시지를 적고(선택) **동행 신청 보내기**를 누릅니다.
4. 상대방에게 알림 문자가 갑니다(연락처가 등록된 경우).

### 받은 신청에 답하기 / 보낸 신청 관리
메뉴의 **내 신청함**에서 확인합니다.

- **받은 신청** 탭: 요청 하나하나에 **수락** 또는 **거절**로 답합니다. 답하면 신청한 분에게 결과 문자가 갑니다.
- **보낸 신청** 탭: 상대가 아직 답하지 않은 신청은 **취소**할 수 있습니다.
- 이미 수락·거절·취소된 신청은 다시 바꿀 수 없습니다.

## 5. 코인 충전

쪽지와 통화는 **코인**으로 이용합니다. **1코인 = 1원**입니다.

| 이용 항목 | 사용 코인 |
|---|---|
| 쪽지 1건 (글·사진·파일 모두) | 500코인 |
| 보이스톡 | 1초당 10코인 (1분 600코인) |
| 페이스톡 | 1초당 100코인 (1분 6,000코인) |

### 충전 신청
1. 화면 위 **○○ 코인** 배지 또는 메뉴의 **코인 충전**을 엽니다.
2. **충전할 금액(원)**을 입력합니다. 최소 1,000원부터 가능합니다.
3. **충전 신청하기**를 누르면 신청이 접수됩니다(상태: 대기중).
4. 안내받은 계좌로 입금합니다. **입금 계좌: (운영진이 별도 안내 — 아래 참고)**
5. 운영진이 입금을 확인해 승인하면 즉시 코인이 들어오고 문자로 알려드립니다.

> 충전 신청만으로는 코인이 지급되지 않습니다. 입금이 확인되어야 승인됩니다. 신청 후 입금 안내가 오지 않으면 고객센터로 문의해 주세요.

### 충전 내역
같은 창 아래 **충전 내역**에서 신청별 상태(대기중 / 승인됨 / 거절됨)와 운영진 메모를 볼 수 있습니다. 거절된 경우 사유가 표시됩니다.

## 6. 쪽지함(채팅)

다른 회원과 카카오톡처럼 대화방 형태로 대화합니다. 운영진(관리자) 계정에는 쪽지를 보낼 수 없으니 [고객센터](#8-고객센터-문의환불신고)를 이용해 주세요.

### 대화 시작하기
1. 메뉴의 **쪽지함**을 엽니다. 대화 이력이 있는 회원이 최근 순으로 보입니다.
2. **새 대화 시작**을 눌러 대화할 회원을 고르면 대화창이 열립니다.

### 메시지 보내기
- 글은 **200자까지** 입력할 수 있습니다(입력창 아래에 글자 수 표시).
- **전송**을 누르면 **500코인**이 차감됩니다. 코인이 부족하면 전송되지 않으며 충전이 필요합니다.
- 😊 **이모티콘**: 감정 표현 이모티콘 30종을 눌러 입력창에 넣을 수 있습니다.
- 📎 **사진/파일 첨부**: 이미지(jpg/png/gif/webp)와 문서(pdf, word, excel, ppt, txt, zip)를 **15MB까지** 보낼 수 있습니다. 파일과 함께 설명 글도 적을 수 있고, 첨부해도 요금은 메시지 1건(500코인)입니다.
- 첨부파일은 **그 대화의 두 사람만** 내려받을 수 있습니다.

### 새 쪽지 알림
- 사이트에 접속해 있으면 15초마다 새 쪽지를 확인해 **알림음과 안내창**으로 알려드리고, 메뉴의 **쪽지함 (숫자)**에 안 읽은 개수가 표시됩니다.
- 대화창을 열어 둔 동안에는 상대의 새 메시지가 몇 초 안에 자동으로 나타납니다.
- 사이트에 접속해 있지 않을 때는 연락처로 문자가 갑니다.

### 알아두세요
- 받은 쪽지는 **회원당 최대 100건**만 보관되며, 넘으면 가장 오래된 것부터 자동 삭제됩니다. 중요한 내용은 따로 보관해 주세요.
- 메시지는 보낸 뒤에 삭제하거나 취소할 수 없습니다.

## 7. 보이스톡·페이스톡

대화창 위쪽의 🎙(보이스톡) 또는 🎥(페이스톡) 버튼으로 화면 안에서 바로 통화합니다. 별도 앱 설치는 필요 없습니다.

### 통화하는 법
1. 대화창에서 🎙 또는 🎥 버튼을 누릅니다.
2. 브라우저가 마이크(페이스톡은 카메라도) 사용 권한을 물으면 **허용**합니다.
3. 상대 대화창에 **통화 참여하기** 버튼이 생깁니다. 상대가 누르면 통화가 연결됩니다.
4. 종료하려면 통화창을 닫거나 통화 종료 버튼을 누릅니다.

### 요금과 잔액 기준
- 통화 요청 자체에는 쪽지 요금(500코인)이 들지 않고, **연결된 뒤 초 단위로** 과금됩니다.
- **통화에 참여한 각자의 코인**에서 차감됩니다. (통화를 건 사람과 받은 사람 모두 자기 잔액에서 사용)
- 통화를 **시작하거나 참여하려면 보유 코인이 3,000코인을 넘어야** 합니다.
- 통화 중 보유 코인이 **1,500코인 이하**로 내려가면 통화가 자동 종료됩니다. 통화 전에 여유 있게 충전해 두세요.
- 상대가 통화를 끊고 혼자 남으면 내 통화도 자동으로 종료되어 요금이 멈춥니다.

### 통화가 안 될 때
- "통화 기능이 아직 설정되지 않았어요"라고 나오면 아직 통화 서비스가 준비되지 않은 상태입니다.
- 연결이 20초 넘게 지연되면 자동으로 중단됩니다. 네트워크를 확인하고 다시 시도해 주세요.
- 통화 화면이 열리지 않으면 페이지를 새로고침한 뒤 다시 시도해 주세요.

## 8. 고객센터: 문의·환불·신고

메뉴의 **고객센터**에서 운영진에게 전달할 내용을 접수합니다. 처리 상태는 같은 창의 **내 문의 내역**에서 확인합니다.

### 문의 유형
| 유형 | 용도 |
|---|---|
| 클레임/불만 | 이용 중 불편 사항 |
| 환불 요청 | 코인 환불. **관련 충전 내역(선택)**을 골라 연결하면 처리가 빠릅니다 |
| 회원 신고 | 불량 회원 신고. **신고할 회원**을 선택합니다 |
| 기타 요청 | 그 밖의 문의 |

### 접수 방법
1. 문의 유형을 고르고 제목과 내용을 입력합니다(둘 다 필수).
2. **접수하기**를 누릅니다.

### 처리 상태
대기중 → 처리중 → 처리완료 또는 반려 순으로 바뀌며, 상태가 바뀔 때마다 문자로 알려드립니다. 운영진 메모도 함께 표시됩니다. 환불이 승인되면 코인이 지급되며 지급된 코인 수가 표시됩니다.

### 회원 신고와 이용 제한
- 신고는 운영진이 확인합니다. 허위 신고는 삼가 주세요.
- 한 회원에 대한 신고가 **3건** 쌓이면 해당 회원에게 경고 문자가 가고, **5건**이 되면 계정이 자동으로 정지됩니다.
- 정지된 계정은 로그인할 수 없고 정지 사유가 안내됩니다. 정지에 대한 문의는 운영진에게 해 주세요.

## 9. 알림 문자

연락처를 등록하면 아래 상황에서 문자(또는 카카오 알림톡)가 옵니다.

- 회원가입 완료, 멤버십 지원서 접수, 지원서 승인/거절
- 동행 신청을 받았을 때, 내 동행 신청에 답이 왔을 때
- 비밀번호 재설정 인증코드
- 코인 충전 승인/반려, 환불 처리
- 새 쪽지 도착
- 본인 인증 승인/반려
- 고객센터 문의 처리 상태 변경
- 신고 누적 경고/정지 안내
- 운영진의 공지·안내

연락처를 등록하지 않으면 문자를 받을 수 없으니 [내 프로필](#3-내-프로필-관리)에서 등록해 두세요.

## 10. 자주 묻는 질문

**Q. 가입했는데 왜 멤버가 아닌가요?**
회원가입과 멤버십은 별개입니다. 멤버십은 지원서 제출 → 심사 → 인터뷰 → 승인 순으로 진행됩니다.

**Q. 코인을 충전했는데 잔액이 그대로예요.**
충전 신청 후 입금이 확인되어 운영진이 승인해야 반영됩니다. **충전 내역**의 상태가 "대기중"이면 승인 전입니다. 입금 후 오래 지나도 그대로면 고객센터로 문의하세요.

**Q. 쪽지를 보냈는데 "코인이 부족해요"가 나와요.**
쪽지는 1건당 500코인이 필요합니다. 코인을 충전해 주세요.

**Q. 갑자기 로그아웃됐어요.**
다른 기기나 브라우저에서 같은 계정으로 로그인하면 이전 로그인은 자동으로 로그아웃됩니다. 계정이 정지된 경우에도 로그아웃되며 다시 로그인할 수 없습니다.

**Q. 실수로 보낸 쪽지를 취소할 수 있나요?**
보낸 쪽지는 취소·삭제할 수 없고 차감된 코인도 자동 환불되지 않습니다. 사정이 있다면 고객센터의 **환불 요청**으로 문의해 주세요.

**Q. 통화 중에 갑자기 끊겼어요.**
보유 코인이 1,500코인 이하로 내려가면 자동 종료됩니다. 상대방이 먼저 나가도 내 통화가 종료됩니다.

**Q. 내 프로필 정보는 누가 보나요?**
프로필 사진과 입력한 정보(연령대, 지역, 직업, 골프 구력, 소개, 인증 배지)는 동행 신청 후보 목록 등에서 다른 로그인 회원에게 보입니다. 신분증 사진은 본인과 관리자만 볼 수 있습니다.

**Q. 요청이 너무 많다며 막혀요.**
스팸 방지를 위해 가입, 로그인, 지원서, 충전, 쪽지, 문의 등에 시간당 횟수 제한이 있습니다. 잠시 후 다시 시도해 주세요.
