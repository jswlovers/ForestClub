# 포레스트클럽 Android

Android 6.0(API 23) 이상용 네이티브 앱입니다. 별도 웹사이트를 열지 않고 Android 화면에서 회원 서비스를 이용합니다.

## 운영 서버

`https://forest.sean2022.one:8888`에 자동 연결합니다. 사용자가 서버 주소를 입력할 필요가 없습니다. HTTPS 인증서 검증을 유지합니다.

- 홈, 골프·여행 검색, 모임 상세와 참가 문의
- 회원가입: 약관 동의 → 가입 가능 여부 확인 → 회원 정보 입력 → 가입 심사 접수
- 로그인·로그아웃, Android Keystore의 AES-GCM으로 암호화한 세션 보관 및 재실행 복원
- 프로필 조회·저장, 멤버십 심사 상태
- 동행 신청과 받은/보낸 신청의 수락·거절·취소
- 쪽지 목록과 대화, 텍스트·파일 전송, 사진/PDF 앱 내부 보기
- 코인 사용 가능 잔액·충전 신청·충전 및 사용 내역
- 고객센터 문의·환불 문의·회원 신고와 답변

쪽지 발송은 기존 서버 정책에 따라 500코인이 필요합니다. 충전 신청은 관리자의 입금 확인과 승인 후 반영됩니다. 파일은 15MB까지 전송할 수 있습니다. 문서 중 이미지/PDF 이외의 형식은 설치된 문서 앱으로 엽니다. 프로필 사진 업로드는 포함되지 않습니다.

보이스톡: 대화창의 '보이스톡' 버튼으로 걸고, 앱이 열려 있으면 받기/거절 창이 뜹니다. 대화의 통화 메시지를 눌러도 참여할 수 있습니다. 통화 중 초당 10코인이 사용되며 잔액 기준은 웹과 같습니다. 페이스톡(영상)은 웹사이트에서 이용합니다. 앱이 꺼져 있을 때의 착신 알림(푸시)은 아직 지원하지 않습니다. 처음 통화할 때 마이크 권한을 묻습니다.

## APK 설치

`artifacts/ForestClub-Android-debug-build3.apk`를 Android 기기에 복사해 열고 해당 설치 앱의 '알 수 없는 앱 설치'를 허용합니다.

이 APK는 개발 테스트용 인증서로 서명되어 있으며 유료 개발자 계정 없이 직접 설치할 수 있습니다. Play Store 배포용 빌드는 별도 배포 서명 설정이 필요합니다. 개인 키는 리포지토리에 포함하지 않습니다.

## 빌드

Android Studio에서 이 `android` 폴더를 엽니다. Java 17과 Android SDK 35가 필요합니다. SDK 경로를 Android Studio가 생성한 `local.properties` 또는 환경 변수로 설정합니다.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Windows에서는 `gradlew.bat`를 사용합니다. Gradle Wrapper 버전과 공식 배포 체크섬을 고정했습니다. 생성한 APK는 빌드 번호를 포함한 이름으로 리포지토리 `artifacts/`에 복사합니다.

## 테스트

단위 테스트 9개는 로그인 쿠키 공유, 재실행 복원, 비밀번호 미보관, 로그아웃·만료, 서버별 쿠키 분리, HTTPS 검증, 숫자 충전 요청과 보이스톡 통화방 주소 검증, 착신 유효 시간, iOS와 공유하는 통화 페이지 일치 여부를 확인합니다.

기기 테스트는 실제 Android Keystore 암호화 및 복원, 쪽지 전송, 코인 잔액 갱신, 프로필 및 다른 회원 API의 공유 로그인을 확인합니다. Android 에뮬레이터가 필요합니다. 저장소 루트의 별도 터미널에서:

```sh
python3 scripts/tests/ios-native-api.py
```

`android` 폴더에서:

```sh
./gradlew connectedDebugAndroidTest
```

테스트는 `10.0.2.2:18743`의 로컬 fixture에만 인증 정보를 전송합니다. 운영 서버에는 테스트 가입·쪽지·충전 데이터를 만들지 않습니다.

검증 환경: Android 15(API 35) 에뮬레이터. APK 빌드, 단위 테스트 6개, 기기 테스트 1개, Lint 오류 0개를 확인했습니다. 실제 Android 기기 및 운영 서버의 가입·심사·결제 전체 흐름은 별도 검증이 필요합니다.
