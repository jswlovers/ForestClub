# 포레스트클럽

골프·여행 프리미엄 멤버십 랜딩 사이트 + 회원/지원서/동행 신청 백엔드.

## 실행 방법

```bash
npm install
npm start          # http://localhost:3000
```

개발 중에는 `npm run dev`로 실행하면 파일 변경 시 자동 재시작됩니다.

첫 실행 시 SQLite DB가 `data/forest-club.sqlite`에 자동 생성되고, 관리자 계정이 자동으로 만들어집니다.
기본 관리자 계정은 `admin@forestclub.kr` / `admin1234!` 이며, 운영 배포 전 `.env`에 `ADMIN_EMAIL`, `ADMIN_PASSWORD`를 지정해 바꿔주세요.
이미 가입한 다른 회원을 관리자로 승격시키려면 `npm run make-admin -- someone@example.com`을 실행하세요.

- 회원 사이트: `/`
- 관리자 페이지: `/admin.html`

## 운영 배포 전 확인할 것

- `.env`의 `ADMIN_EMAIL`, `ADMIN_PASSWORD`를 실제 값으로 변경
- HTTPS로 서비스한다면 `NODE_ENV=production`으로 설정 (세션 쿠키에 secure 플래그 적용)
- Nginx 등 리버스 프록시 뒤에 있다면 `TRUST_PROXY=true`로 설정해야 요청 제한(rate limit)이 실제 클라이언트 IP를 정확히 봄 (프록시 없이 켜면 요청 제한이 우회될 수 있으니 주의)

## 알림 (SMS / 카카오 알림톡)

`.env.example`을 복사해 `.env`로 만든 뒤 값을 채워주세요.

```bash
cp .env.example .env
```

기본값(`SMS_PROVIDER=mock`, 카카오 키 없음)에서는 실제로 발송되지 않고, 콘솔 로그와 관리자 페이지의 "알림 발송 로그" 탭에만 기록됩니다.

- **SMS**: Solapi 계정과 API 키가 있다면 `SMS_PROVIDER=solapi`로 바꾸고 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER`를 채우면 바로 실제 발송으로 전환됩니다 (코드 수정 불필요).
- **카카오 알림톡**: [카카오 비즈니스 채널](https://business.kakao.com)을 만들고 알림 종류별 템플릿을 등록해 심사 승인을 받으면, `KAKAO_PF_ID`와 승인된 `KAKAO_TEMPLATE_*` 값을 `.env`에 채워주세요 (SOLAPI_* 키도 함께 필요). 채워진 종류의 알림부터 SMS 대신 알림톡으로 자동 전환되고, 알림톡 발송이 실패하면 문자로 자동 대체됩니다. 템플릿을 등록하지 않은 종류는 그대로 SMS(또는 mock)로 발송됩니다.

현재 다음 상황에서 자동으로 알림을 보냅니다:
- 회원가입 완료 (연락처를 입력한 경우)
- 멤버십 지원서 접수
- 지원서 승인/거절 (관리자 처리)
- 동행 신청을 받았을 때
- 동행 신청에 대한 수락/거절 응답
- 비밀번호 재설정 인증코드 요청
- 코인 충전 승인/반려
- 새 쪽지 도착

## 카카오톡 발송 (관리자 → 회원)

관리자 페이지의 **카카오톡 발송** 탭에서 회원에게 카카오톡 메시지를 보냅니다. 대상은 전체/멤버십 승인 회원/본인 인증 회원/골프·여행 관심 회원/특정 회원 중에서 고르고, 발송 전에 인원과 실제 문구를 미리 확인할 수 있으며, 발송 이력은 `kakao_campaigns` 테이블과 "알림 발송 로그"에 남습니다.

- **알림톡**: 결제 확인, 일정 변경 같은 정보성 안내. `KAKAO_TEMPLATE_ADMIN_NOTICE`(변수 `#{message}` 하나) 템플릿이 승인돼 있어야 실제 발송됩니다. 수신 동의 없이 보낼 수 있고, 카카오 발송이 실패하면 문자로 대체됩니다.
- **친구톡**: 자유 문구의 광고성 소식. 프로필에서 광고 수신에 동의한 회원(`users.marketing_opt_in_at`)에게만 보내고, `(광고)[포레스트클럽]` 표기와 `무료수신거부: 채널 차단` 문구를 자동으로 붙이며, 20:50~08:00(KST)에는 발송을 막습니다. 채널 친구가 아닌 회원은 카카오 쪽에서 실패 처리되고 문자로 대체하지 않습니다.
- `SOLAPI_*`, `KAKAO_PF_ID`가 없으면 **모의 발송**(기록만 남김)으로 동작합니다. 친구톡은 `SOLAPI_*`와 `KAKAO_PF_ID`만 있으면 실제 발송되고, 알림톡은 `KAKAO_TEMPLATE_ADMIN_NOTICE`까지 있어야 합니다.
- 한 번에 최대 1,000명, 관리자당 10분에 10회까지 발송할 수 있습니다.
- 관련 코드: `server/services/kakao-campaign.js`(대상 선정·정책·발송), `server/routes/kakao-admin.js`(API), `server/services/kakao.js`(`sendFriendtalk`).

## 코인 · 쪽지

회원은 코인을 충전해 다른 회원에게 쪽지(메시지)를 보낼 수 있습니다. 1코인 = 1원, 쪽지 1건 발송에 500코인(500원 상당)이 사용됩니다.

- **충전**: 회원이 "코인 충전"에서 금액을 입력해 충전을 신청하면(최소 1,000원) `pending` 상태로 접수됩니다. 기본값은 무통장입금 방식으로, 관리자가 입금을 확인하고 관리자 페이지의 "코인 충전 승인" 탭에서 승인하면 즉시 코인이 지급됩니다.
- **토스페이먼츠 연동(선택)**: `.env`에 `TOSS_SECRET_KEY`를 채우면 `/api/coins/toss/confirm` 결제 승인 API 연동이 활성화됩니다. 단, 토스 결제위젯(클라이언트 키, 체크아웃 UI)은 별도로 프론트엔드에 붙여야 합니다 — 지금은 서버 쪽 승인 로직만 준비되어 있고, 프론트는 무통장입금(관리자 수동승인) 흐름만 노출합니다.
- **원장**: 모든 코인 충전/사용은 복식부기(더블 엔트리) 원장(`coin_ledger`)에 기록됩니다. 거래 하나당 차변·대변 두 줄이 항상 짝을 이루고(충전: 플랫폼 현금 차변 / 회원 코인계정 대변, 쪽지 발송: 회원 코인계정 차변 / 플랫폼 매출 대변), 회원 잔액은 캐시된 컬럼이 아니라 이 원장에서 매번 계산됩니다. 관리자 페이지의 "코인 원장" 탭에서 전체 내역을 볼 수 있습니다.
- **쪽지**: 채팅(대화방) 형태로 동작하며, 코인이 부족하면 발송이 거부됩니다(402). 회원별 받은 쪽지함은 최대 100개까지만 보관되며, 초과분은 가장 오래된 것부터 자동 삭제됩니다.
- **새 쪽지 알림**: 사이트에 접속해 있는 동안 15초마다 안 읽은 쪽지 수를 확인해, 늘어나면 소리(브라우저 내장 오디오로 생성, 별도 파일 없음)와 토스트로 알려주고 헤더에 숫자 배지로 표시합니다.
- **이모티콘**: 채팅 입력창의 😊 버튼으로 감정 표현 위주 이모티콘 30종을 바로 입력할 수 있습니다.
- **사진/파일 전송**: 채팅에서 📎 버튼으로 이미지(jpg/png/gif/webp)나 문서(pdf/word/excel/ppt/txt/zip)를 최대 15MB까지 첨부할 수 있습니다. 첨부파일은 `data/uploads/`에 저장되고, 해당 대화의 당사자만 내려받을 수 있도록 인증된 경로로만 제공됩니다.
- **보이스톡/페이스톡(선택)**: 채팅 상단의 🎙/🎥 버튼으로 통화방을 만듭니다. [Daily.co](https://dashboard.daily.co) 무료 계정을 만들고 `.env`에 `DAILY_API_KEY`를 채우면 실제 통화방이 생성됩니다 (WebRTC 시그널링·TURN 서버를 Daily.co가 대신 처리). 키가 없으면 "아직 준비되지 않았어요" 안내만 뜹니다. 직접 WebRTC를 구현하지 않은 이유: TURN 서버 없이는 같은 네트워크가 아닌 회원 간 통화 연결이 실패할 수 있어서, 무료 티어를 제공하는 외부 서비스 연동이 훨씬 안정적입니다.

## 주요 기능

- 회원가입/로그인 (서버 세션 기반, 비밀번호는 scrypt로 해시 저장)
- 비밀번호 변경(로그인 상태) 및 비밀번호 재설정(SMS 인증코드 기반, 비로그인 상태)
- 내 프로필 관리 — 연락처/연령대/지역/직업/골프구력/관심분야/소개를 직접 입력·수정 (동행 신청 시 다른 회원에게 노출됨)
- 멤버십 지원서 제출, 제출자 본인이 "내 지원 현황"에서 심사 상태·운영진 메모 확인
- 관리자 승인/거절 (거절 시 사유를 입력하면 알림 문구와 지원자 화면에 함께 표시, 중복 처리 방지)
- 골프·여행 모임 "참가 문의" 접수, 정원/남은 자리는 실제 문의 수 기반으로 자동 계산되어 표시
- 회원 간 "동행 신청" — 특정 모임에 함께할 회원을 지목해 신청 → 상대에게 알림 → 수락/거절/취소 → 신청자에게 결과 알림
- 관리자 페이지(`/admin.html`): 회원 관리, 지원서 심사, 동행 신청 현황, 참가 문의, 알림 발송 로그
- 코인 충전(무통장입금 신청 → 관리자 승인) 및 회원 간 유료 채팅(500코인/건, 복식부기 원장으로 관리)
- 채팅에서 이모티콘, 사진/파일 첨부, 보이스톡·페이스톡(Daily.co 연동, 키 설정 전까지는 준비중 안내) 지원
- 안 읽은 쪽지 실시간(폴링) 알림 — 소리 + 헤더 숫자 배지
- 가입/로그인/지원서/동행신청/비밀번호 재설정/코인 충전/쪽지 발송에 기본 요청 빈도 제한(레이트 리밋) 적용 — 초대제 멤버십 특성상 스팸·봇 가입 방지
- `npm run make-admin -- <email>`로 기존 회원을 관리자로 승격
