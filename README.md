# 포레스트클럽

골프·여행 프리미엄 멤버십 랜딩 사이트 + 회원/지원서/동행 신청 백엔드.

## 실행 방법

```bash
npm install
npm start          # http://localhost:3000
```

개발 중에는 `npm run dev`로 실행하면 파일 변경 시 자동 재시작됩니다.

첫 실행 시 SQLite DB가 `data/forest-club.sqlite`에 자동 생성되고, 관리자 계정이 자동으로 만들어집니다.
기본 관리자 계정은 `admin@forestclub.kr` / `admin1234!` 이며, 운영 배포 전 `.env`에 `ADMIN_EMAIL`, `ADMIN_PASSWORD`를 지정해 바꿔주세요.
이미 가입한 다른 회원을 관리자로 승격시키려면 `npm run make-admin -- someone@example.com`을 실행하세요.

- 회원 사이트: `/`
- 관리자 페이지: `/admin.html`

## 운영 배포 전 확인할 것

- `.env`의 `ADMIN_EMAIL`, `ADMIN_PASSWORD`를 실제 값으로 변경
- HTTPS로 서비스한다면 `NODE_ENV=production`으로 설정 (세션 쿠키에 secure 플래그 적용)
- Nginx 등 리버스 프록시 뒤에 있다면 `TRUST_PROXY=true`로 설정해야 요청 제한(rate limit)이 실제 클라이언트 IP를 정확히 봄 (프록시 없이 켜면 요청 제한이 우회될 수 있으니 주의)

## 알림 (SMS / 카카오 알림톡)

`.env.example`을 복사해 `.env`로 만든 뒤 값을 채워주세요.

```bash
cp .env.example .env
```

기본값(`SMS_PROVIDER=mock`, 카카오 키 없음)에서는 실제로 발송되지 않고, 콘솔 로그와 관리자 페이지의 "알림 발송 로그" 탭에만 기록됩니다.

- **SMS**: Solapi 계정과 API 키가 있다면 `SMS_PROVIDER=solapi`로 바꾸고 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER`를 채우면 바로 실제 발송으로 전환됩니다 (코드 수정 불필요).
- **카카오 알림톡**: [카카오 비즈니스 채널](https://business.kakao.com)을 만들고 알림 종류별 템플릿을 등록해 심사 승인을 받으면, `KAKAO_PF_ID`와 승인된 `KAKAO_TEMPLATE_*` 값을 `.env`에 채워주세요 (SOLAPI_* 키도 함께 필요). 채워진 종류의 알림부터 SMS 대신 알림톡으로 자동 전환되고, 알림톡 발송이 실패하면 문자로 자동 대체됩니다. 템플릿을 등록하지 않은 종류는 그대로 SMS(또는 mock)로 발송됩니다.

현재 다음 상황에서 자동으로 알림을 보냅니다:
- 회원가입 완료 (연락처를 입력한 경우)
- 멤버십 지원서 접수
- 지원서 승인/거절 (관리자 처리)
- 동행 신청을 받았을 때
- 동행 신청에 대한 수락/거절 응답
- 비밀번호 재설정 인증코드 요청

## 주요 기능

- 회원가입/로그인 (서버 세션 기반, 비밀번호는 scrypt로 해시 저장)
- 비밀번호 변경(로그인 상태) 및 비밀번호 재설정(SMS 인증코드 기반, 비로그인 상태)
- 내 프로필 관리 — 연락처/연령대/지역/직업/골프구력/관심분야/소개를 직접 입력·수정 (동행 신청 시 다른 회원에게 노출됨)
- 멤버십 지원서 제출, 제출자 본인이 "내 지원 현황"에서 심사 상태·운영진 메모 확인
- 관리자 승인/거절 (거절 시 사유를 입력하면 알림 문구와 지원자 화면에 함께 표시, 중복 처리 방지)
- 골프·여행 모임 "참가 문의" 접수
- 회원 간 "동행 신청" — 특정 모임에 함께할 회원을 지목해 신청 → 상대에게 알림 → 수락/거절/취소 → 신청자에게 결과 알림
- 관리자 페이지(`/admin.html`): 회원 관리, 지원서 심사, 동행 신청 현황, 참가 문의, 알림 발송 로그
- 가입/로그인/지원서/동행신청/비밀번호 재설정에 기본 요청 빈도 제한(레이트 리밋) 적용 — 초대제 멤버십 특성상 스팸·봇 가입 방지
- `npm run make-admin -- <email>`로 기존 회원을 관리자로 승격
